# debug-tool (source-first)

本仓库采用“源码优先”策略：

- 只提交可编辑源码、前端资源、配置模板、脚本与文档
- 不提交大体积二进制（`*.exe`）和本机运行产物（日志/数据库/WebView 缓存）
- 如需可执行发布包，请通过 Release/网盘分发，不放入 Git 主仓

## 当前目录

- `unified-tool/`：主工程（源码）
- `高德模块/`：仅保留文档类文件，`exe` 已忽略

## 重要说明

当前工程是“恢复源码 + 渐进替换”的状态，部分深层逻辑历史上来自运行时字节码。
本仓库默认只保留源码侧内容；运行时发布依赖请按 `unified-tool/BUILDING.md` 准备。
