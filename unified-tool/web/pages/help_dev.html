💻 研发管理 - 使用说明

📌 功能概述

研发管理用于管理单片机工程的源代码、Git版本控制和编译构建。

🚀 快速开始

1

添加工程

点击右上角 ➕ 新建工程 按钮

选择本地的Keil/IAR/GCC工程目录

输入工程名称和目标芯片型号

2

Git操作

如果工程包含 .git 目录，会自动显示Git信息

点击 🔄 Git Pull 拉取最新代码

3

编译构建

选择工程后，系统会自动检测编译器类型

输入版本号（如 1.0.0），点击编译

编译成功后会生成 HEX 文件

4

提交测试

在版本历史中选择编译成功的版本

点击 📤 提交到测试

版本会自动进入测试队列

📂 支持的工程类型

类型识别方式编译命令
Keil MDK.uvprojx 文件UV4.exe -b project.uvprojx
IAR.ewp 文件iarbuild project.ewp
GCC/MakefileMakefile 文件make

⚠️ 注意事项

  • 确保 Keil 安装在默认路径 C:\Keil_v5\UV4\UV4.exe
  • Git 操作需要系统已安装 Git 并配置环境变量
  • 编译输出的 HEX 文件需在 Objects/Output/Build 目录下
