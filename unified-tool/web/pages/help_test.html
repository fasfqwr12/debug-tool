🧪 测试管理 - 使用说明

📌 功能概述

测试管理用于验证研发提交的固件版本，记录测试数据，决定是否发布到生产。

🚀 快速开始

1

查看待测队列

左侧列表显示所有待测试的固件版本

橙色标记 = 等待测试，蓝色标记 = 测试中

2

执行测试

点击待测项，中间区域显示测试表单

逐项勾选测试项目，添加测试备注

填写测试数据（激光功率、电机精度等）

3

查看来源信息

右侧面板显示该版本的构建信息

可查看 Git 提交、编译配置等详情

点击 查看研发详情 跳转到研发页面

4

提交结果

✓ 测试通过 - 版本发布到生产端

✗ 测试不通过 - 退回研发，需输入原因

📋 测试项目说明

测试项测试内容合格标准
基础功能测试开机、按键、指示灯功能正常
激光发射测试激光功率、稳定性功率误差 ≤ 5%
电机控制测试角度精度、响应速度精度 ≤ 0.5°
通讯协议测试串口/蓝牙通讯延迟 ≤ 10ms
功耗测试待机电流、工作电流待机 ≤ 5mA
稳定性测试长时间运行24h无异常

📊 测试数据字段

字段单位说明
激光功率mW使用功率计测量
电机精度°角度误差
通讯延迟ms指令响应时间
待机电流mA待机状态电流
