竞品协议库（本机）
这是做什么的？ 把竞品协议配置化管理成 Profile。滑台测试与顶部工具栏会引用同一个 Profile，实现“写明白协议就能用”，新竞品来不需要改代码（多数情况）。
协议Profile 选择一个profile进行编辑/测试
Profile JSON kind 支持: l1_ascii / custom_ascii / custom_fixed_frame。controls 可选（开激光等）。
操作 保存后，可在滑台设置里选择该profile作为测距来源

📧 SMTP邮件配置
启用邮件通知 任务分配时自动发送邮件
SMTP服务器 如: smtp.qq.com, smtp.163.com
端口 TLS通常为587，SSL通常为465
使用TLS 推荐启用加密传输
用户名 通常是发件邮箱地址
密码/授权码 QQ/163等需使用授权码
发件人名称 邮件中显示的发件人
操作 保存配置后可测试
💡 配置说明

QQ邮箱：smtp.qq.com:587，需在QQ邮箱设置中开启SMTP并获取授权码

163邮箱：smtp.163.com:465(SSL)或25，需开启SMTP并设置客户端授权码

企业邮箱：请联系IT获取SMTP服务器地址和端口

配置完成后，分配任务时会自动发送邮件通知到测试人员邮箱（需在用户管理中填写邮箱）
